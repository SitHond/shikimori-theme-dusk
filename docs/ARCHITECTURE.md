# архитектура shiki dusk

## откуда

тема выросла из однофайлового стиля «purple cozy desk» ([my.original.css](my.original.css), 1 800 строк). в v0.1.0 он разложен по модулям по образцу shiki glass (Hikisey/shikimori-theme):

- 38 разделов файла → 26 модулей в `src/` (порядок — `src/manifest.txt`);
- ~90 жёстко заданных hex-цветов → палитра из rgb-троек (`tokens/palette.css`) и токены компонентов (`tokens/components.css`), оттенки считаются через `color-mix`;
- все правила обёрнуты в `@media screen and (min-width: 1px)`: в старом файле они были без обёртки, и шикимори применял их только на ширине ≥1024 (телефон оставался без темы);
- все `:hover` вынесены в `@media (hover: hover) and (pointer: fine)`, у кнопок, чипов и пунктов меню добавлен отклик `:active` для сенсоров;
- фон перенесён с `body` на `html`: фон `body` закрывал `body::before` с отрицательным `z-index`, и сумеречные пятна света не были видны;
- добавлены свои обои (`--bg-image`, `--bg-dim`) и подпись версии в подвале.

## сборка

`tools/build.py` склеивает модули и раскладывает их целиком по частям ≤150 КБ. сейчас тема — 1 часть (~67 КБ).
пределы шикимори: обрабатываются только ~6 первых `@import` (один занят css-club), файл ~231 КБ уже не импортировался.

## как шикимори загружает css

1. вырезает `@import` и качает каждый адрес своим сервером (таймаут ~5 с, кеш по адресу 8 ч, неудача = пустой файл);
2. чистит: комментарии, опасные слова, обратные слэши, data uri кроме base64-картинок;
3. переписывает ссылки `https://` и `//` на camo-прокси;
4. css без `@media` оборачивает в `@media only screen and (min-width: 1024px)`.

эмуляция шагов 2–3 — `tools/shiki_compile.py` и `tools/shiki_url_check.py` (порт из shiki glass), запускаются из `tools/quick_check.py`.
